## 掼蛋 AI

纯自对弈强化学习训练的掼蛋 AI，带训练中心与局域网对战。

### Windows 免安装版（只打牌）

下载 `guandan_windows.exe`，双击就能打牌、局域网联机，什么都不用装。不能训练。第一次运行如果提示“Windows 已保护你的电脑”，点“更多信息 → 仍要运行”；防火墙询问时勾选“专用网络”。

### 安卓手机（只打牌）

下载 `guandan_android.apk` 在手机上安装（按提示允许浏览器安装应用）。打开就能和 AI 打牌；手机本身就是局域网主机，同一 WiFi 的朋友扫牌桌上的二维码用浏览器加入，不用装 App。不能训练。

### Windows 一键安装（可以训练）

1. 下载下面的 `install_windows.bat`、`install_windows.ps1`、`start_windows.bat`、`train_windows.bat`，放进同一个文件夹。
2. 双击 `install_windows.bat`：自动安装 Python 3.12、CUDA 版 PyTorch（自动匹配显卡驱动）和本程序。
3. 双击 `start_windows.bat` 打开界面。局域网里的朋友用手机扫牌桌上的二维码即可加入。

Linux / macOS：下载对应平台的 `.whl`，`pip install torch guandan_rl-*.whl`，然后运行 `guandan serve`。

### v1.7.2

- **随打随停**：离开牌桌，或者手机切到后台、锁屏几秒，牌局就自动暂停，回来后从原处接着打。实战模式不会再因为你不在而超时乱出牌。几个真人一起打时，有人离开不影响别人：轮到他时由 AI 替他出牌（托管），他回来后接着打。牌桌顶栏新增 ⏸，可以随时手动暂停，点“继续”恢复。
- **同时开几桌**：“开一桌”不再关掉原来的牌桌，最多可以同时开 8 桌（比如你和 AI 练一桌，家人用手机打另一桌）。首页列出所有牌桌的模式、玩家、进度和状态（进行中 / 等人 / 已暂停），可以回到座位、加入或观战。在主机这台电脑上还能暂停、继续或关闭任意一桌。每桌的二维码只加入这一桌。
- **打完一局可以结束牌局**：每局结算时有“下一局 / 结束牌局 / 离开”三个按钮。“结束牌局”把这张桌彻底关掉，桌上的人都回到首页；“离开”只是暂停，进度保留，之后从首页“回到座位”接着打。牌局中途点“离开”时也可以直接结束。

### v1.7.1

- **在已有模型上训练更大的模型**：训练中心选了基准模型后，再选比它更大的“模型大小”（例如 medium → large），会先把基准模型“加宽”：每层复制已有的神经元并把它们的输出权重随机拆分，多出的一层先设成直通。加宽后的大模型开局打法和原模型完全一样（误差小于万分之一），然后在此基础上继续自对弈，不用从零练起。命令行：`--base 模型.pt --preset large`。
- 免安装版实际大小约 32 MB。

### v1.7.0

### 内容

- 完整掼蛋规则：逢人配、钢板、三连对、同花顺、天王炸、进贡 / 还贡 / 抗贡、接风、双上升三级、过 A、打 A 三次不过退回 2
- Rust 规则引擎 + PyTorch 深度蒙特卡洛自对弈训练，模型大小可选（推荐 medium：2.46M 参数，fp16 约 5 MB）
- 训练中心：从零或从基准模型训练，复式评估的胜率曲线（对规则 AI / 基准模型 / 随机）；同一时间只运行一个训练，自对弈进程数按显存和内存自动限制，停止无响应时自动强制结束
- 教学模式（AI 提示、出牌点评、明牌）与实战模式（20 秒限时，超时随机出牌，出完可看队友牌）
- 快速对局（随机级牌）与竞技模式（打到 A）
- `guandan-medium.pt`：随包模型，GPU 自对弈约 8.8 亿样本，只用网络时对规则 AI 每局胜率 83.7%（见 docs/MODEL.md）
