## 掼蛋 AI 预览版

- Rust 规则引擎：完整掼蛋规则（逢人配、各类炸弹与同花顺、进贡/还贡/抗贡、接风、升级、过 A）
- 纯自对弈 Deep Monte-Carlo 训练框架，模型大小可选（推荐 medium，约 2.5M 参数）
- Web 界面：训练中心（实时胜率曲线）、教学模式 / 实战模式、快速对局 / 竞技模式、局域网联机

### Windows 安装
下载 `install_windows.bat`、`install_windows.ps1`、`start_windows.bat` 到同一个文件夹，双击 `install_windows.bat`（自动安装 Python、CUDA 版 PyTorch 和本程序），完成后双击 `start_windows.bat`。
