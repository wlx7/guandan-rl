## 掼蛋 AI

纯自对弈强化学习训练的掼蛋 AI，带训练中心与局域网对战。

### Windows 一键安装

1. 下载下面的 `install_windows.bat`、`install_windows.ps1`、`start_windows.bat`、`train_windows.bat`，放进同一个文件夹。
2. 双击 `install_windows.bat`：自动安装 Python 3.12、CUDA 版 PyTorch（自动匹配显卡驱动）和本程序。
3. 双击 `start_windows.bat` 打开界面。局域网里的朋友用手机扫牌桌上的二维码即可加入。

Linux / macOS：下载对应平台的 `.whl`，`pip install torch guandan_rl-*.whl`，然后运行 `guandan serve`。

### v1.5 新增

- **更强的随包模型（v1.5.1）**：在 v1.4.1 模型上加“预测手牌”辅助任务再练 2 小时。只用网络时对规则 AI 每局胜率 **83.7%**（+1.91 级/局），对 v1.4.1 模型胜率 58.2%（+0.46 级/局）。
- **安装不再占用 C 盘（v1.5.1）**：Python、下载缓存、虚拟环境和训练数据全部放在安装文件夹里，可以把整个文件夹放在 D 盘等任意位置。
- **训练默认加上辅助任务**（`--aux 0.25`）：训练时让网络同时预测其他三家的手牌（对战时不用）。从同一个模型出发各练 2 小时，加辅助任务的模型对普通训练每局多赢 0.39 级（胜率 57.4%），对规则 AI 胜率 83.2%（普通训练 80.4%）。训练中心“更多参数”里可以调。
- **对战默认只用神经网络出牌**：随包模型练强以后，推演搜索反而让它变弱（对规则 AI +1.27 对 +1.52 级/局），“推演搜索”改为实验选项。
- 训练名称如果是 Windows 的保留名（aux、con、nul 等）会自动加上后缀，避免文件夹无法读取。

### v1.4 新增

- **更强的随包模型（v1.4.1）**：继续纯自对弈 3 小时（累计约 6.56 亿样本）。只用网络时对规则 AI 每局胜率 **78.8%**（平均每局 +1.61 级），直接对 v1.3 模型胜率 60.6%（+0.58 级/局），对 v1.1 模型 73%（+1.33 级/局），均为 2000 副牌复式对局。
- 训练新增 `--aux`（实验）：辅助任务，训练时让网络同时预测其他三家的手牌，参考开源掼蛋 AI DanLM / DanKS 的做法；对战时不使用这个输出。
- 模型文件读取更宽容（新版本多出的输出头会被忽略）。

### v1.3 新增

- **更强的随包模型**：在原模型基础上继续纯自对弈训练（累计约 3.14 亿样本）。只用网络时，对规则 AI 每局胜率从 60.7% 提高到 **71.5%**（平均每局 +0.53 → **+1.19** 级），直接对 v1.1 随包模型胜率 65%（复式对局 2000 局）。
- **深度思考更强**：推演时采样的“可能的世界”从 12 个增加到 24 个。在旧模型上实测，对规则 AI 从 +0.50（只用网络）提高到 +0.93 级/局，胜率 68.8%。
- 训练默认回到纯自对弈（ε=0.02）：2+2 小时的对比实验中，纯自对弈明显好于对手池训练（直接对打每局多赢 0.34 级），对手池改为可选项。
- 训练中心的评估记录显示误差范围（±），说明复式评估的含义。

### v1.2

- 对手池训练（可选）、复式评估（每副牌打两遍、交换座位，每次评估用同一批牌）。
- 计分倍数只在快速对局中可选，AI 的打法不受倍数影响。
- `guandan eval` 改为复式对局，可以给双方分别开启推演搜索。

### v1.1 新增

- **AI 深度思考（推演搜索）**：出牌前随机推测对手手牌，把网络认为最好的几手在多个可能的牌局里推演下去，按平均结果出牌。整个过程不用人工规则。
- **计分倍数**：只算升级 / 标准倍数 / 全炸翻倍三种计分可选，牌桌显示实时倍数，结算显示底分 × 倍数。

### 内容

- 完整掼蛋规则：逢人配、钢板、三连对、同花顺、天王炸、进贡 / 还贡 / 抗贡、接风、双上升三级、过 A、打 A 三次不过退回 2
- Rust 规则引擎 + PyTorch 深度蒙特卡洛自对弈训练，模型大小可选（推荐 medium：2.46M 参数，fp16 约 5 MB）
- 训练中心：从零或从基准模型训练，复式评估的胜率曲线（对规则 AI / 基准模型 / 随机）；同一时间只运行一个训练，自对弈进程数按显存和内存自动限制，停止无响应时自动强制结束
- 教学模式（AI 提示、出牌点评、明牌）与实战模式（20 秒限时，超时随机出牌，出完可看队友牌）
- 快速对局（随机级牌）与竞技模式（打到 A）
- `guandan-medium.pt`：随包模型，GPU 自对弈约 8.8 亿样本，只用网络时对规则 AI 每局胜率 83.7%（见 docs/MODEL.md）
