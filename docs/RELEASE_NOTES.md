## 掼蛋 AI

纯自对弈强化学习训练的掼蛋 AI，带训练中心与局域网对战。

### Windows 免安装版（只打牌）

下载 `guandan_windows.exe`，双击就能打牌、局域网联机，什么都不用装。不能训练。第一次运行如果提示“Windows 已保护你的电脑”，点“更多信息 → 仍要运行”；防火墙询问时勾选“专用网络”。

### Windows 一键安装（可以训练）

1. 下载下面的 `install_windows.bat`、`install_windows.ps1`、`start_windows.bat`、`train_windows.bat`，放进同一个文件夹。
2. 双击 `install_windows.bat`：自动安装 Python 3.12、CUDA 版 PyTorch（自动匹配显卡驱动）和本程序。
3. 双击 `start_windows.bat` 打开界面。局域网里的朋友用手机扫牌桌上的二维码即可加入。

Linux / macOS：下载对应平台的 `.whl`，`pip install torch guandan_rl-*.whl`，然后运行 `guandan serve`。

### v1.7.0

- **新增免安装版 `guandan_windows.exe`**：一个约 40 MB 的文件，双击就能打牌和局域网联机，不用装 Python、PyTorch 等依赖。它用 numpy 运行神经网络（和 PyTorch 的结果误差在百万分之一以内，出牌完全一样），所以不能训练、也没有实验性的“推演搜索”；训练仍用一键安装版。把 exe 放进安装文件夹（如 `D:\guandan`），可以直接用那里的模型。
- 没装 PyTorch 时（免安装版或只装了程序），训练中心会说明只能对战，不再报错。

### v1.6.9

- **修复手机上选不上牌**：快速依次点同一列里的两张牌（比如一对），浏览器会把它当成“双击整列”，结果两张牌一起被取消。现在只有在同一张牌上连点两下才算双击整列。
- **手机牌桌更清爽**：手机上不再在每手出牌下面显示“单张 8”“对子 9”之类的牌型说明；AI 座位只显示头像和剩余张数，不再多一行名字，别人出的牌离头像更近、不挤在一起。
- **头游 / 二游标签不再闪**：标签只在玩家出完牌那一刻盖章一次，之后别人出牌时保持不动。

### v1.6.8

- **这台电脑可以只做主机**：开桌时“这台电脑”选“只做主机”，电脑只运行 AI 和显示牌桌，玩家座位留给手机等其他设备扫码入座；只有一个真人时，可以只用手机和三个 AI 打（电脑屏幕上看不到任何人的手牌）。
- **花色改用矢量图形绘制**：手机浏览器会把 ♠♥♣♦ 显示成大小不一的表情字体，叠在一列的牌上会被下一张遮住；现在花色和点数一样大小可控，始终完整显示在每张牌露出的那一条里。
- **选中的牌改成蓝色**，和金色的逢人配区分开；逢人配的“配”字紧跟在点数花色后面，不再盖住花色。
- **小屏手机（带浏览器地址栏时）显示更清楚**：手牌高度会给牌桌留出足够空间，别人出的牌不再和按钮、你自己的出牌叠在一起；牌型名称叠在出的牌下部；开记牌器时级牌牌匾移到左边，记牌器不再盖住它；横屏时工具条保持一行。

- **新增“全屏”按钮（⛶）**：手机浏览器里点一下隐藏地址栏，牌桌更大（Android 上会顺便锁定横屏）。

### v1.6.5（界面参照欢乐斗地主的掼蛋）

- **手牌改成“站立”排列**：每个点数（或理好的组合）一列，各列底部对齐、向上叠放，每张被压住的牌都露出一条写着点数和花色的“牌头”，列与列之间尽量不重叠，手机上每张牌都是够大的点击区域。
- **选中的牌变成金色，不再上移**，不会再挡住上面的牌。
- **出牌按钮浮在牌桌上**（手牌正上方），轮到你时自动出现；工具条压在手牌底边：左边“一键理牌 / 恢复”，中间“同花顺 ♠♥♣♦”，右边“理牌（把选中的牌放成一列）/ 重选 / 记牌器 / 明牌”。
- **同花顺快选**：点花色一键选出该花色的同花顺（会用上逢人配），再点换下一个；没有的花色是灰的。
- 出的牌显示得更大；手机横屏时顶栏和按钮更紧凑，牌桌留出更多空间。

### v1.6.4

- **手牌能看清花色**：叠在一列里的牌，露出的那一条同时显示点数和花色。
- **手机上牌更大、更好点**：横屏手机上手牌高度从约 49 像素加大到约 85 像素；竖屏时手牌自动分成两行。
- **一键理牌 / 恢复**：把天王炸、炸弹、同花顺、钢板、三连对、顺子、三带二、三张、对子、单张各放一列，列底标出牌型；双击一列可整列选中，再点“恢复”回到按点数排列。
- **记牌器**：可开关，显示其他三家手里还剩的每个点数的张数（级牌高亮），设置会被记住。

### v1.6.3

- **模型列表更清爽**：选择模型时按“内置 / 模型库 / 训练”分组，每个训练只列出最新模型（各阶段快照仍保留，可在训练中心“加入模型库”）。
- **可以改名和隐藏**：训练中心里每个训练有“改名”“隐藏”按钮，“基准模型”下方的“整理模型列表”可以一次整理所有模型。只改显示名称、不删除文件，隐藏的随时可以恢复。
- 训练中心默认收起已隐藏的训练（正在训练的总会显示）。

### v1.6.2

- **更强的随包模型**：自动调参（每轮几组设置对比、保留明显更好的）又练了 4.5 小时，累计约 17.7 亿样本。只用网络时对规则 AI 每局胜率 **89.1%**（+2.25 级/局），直接对 v1.6.1 随包模型每局多赢 **0.28 级**（胜率 54.9%），均为 2000 副牌复式对局。
- **显卡训练默认批大小改为 4096**（原来 2048）：对比实验中每局多赢 0.10 ± 0.03 级。
- **学习率默认自动**：从头训练 2e-4；选了基准模型、在已有模型上继续训练时 5e-5。继续训练强模型时，小学习率每局多赢约 0.10 级。
- 训练日志开头会显示实际使用的学习率。

### v1.6.1

- **更强的随包模型**：在 v1.6.0 随包模型上把“预测手牌”辅助任务的权重调到 1.0，再自对弈 2.75 小时（累计约 12 亿样本）。只用网络时对规则 AI 每局胜率 **87.5%**（+2.09 级/局），直接对 v1.6.0 随包模型每局多赢 **0.35 级**（胜率 56.7%），均为 2000 副牌复式对局。
- **训练默认辅助任务权重改为 1.0**（原来 0.25）：从同一模型出发各练 1.5 小时，权重 1.0 的模型直接对打每局多赢 0.15 ± 0.03 级。
- 推演搜索（实验）改为“只有在同一批模拟里明显更好（超过 2 个标准误差）时才推翻网络的选择”，比之前稳得多，但对强模型仍然不如只用网络，所以对战依旧默认只用网络。

### v1.6 新增（实验功能，效果正在测试）

- 训练新增 `--ntp`：辅助任务，让网络根据出牌历史预测下一手出牌（参考 DanLM 的“预测下一个 token”）。
- 推演搜索新增“按网络推断采样手牌”：用辅助任务学到的手牌预测来推测对手手牌，比平均分配更接近真实手牌（重合度 56% 对 49%）。

### v1.5 新增

- **更强的随包模型（v1.5.1）**：在 v1.4.1 模型上加“预测手牌”辅助任务再练 2 小时。只用网络时对规则 AI 每局胜率 **83.7%**（+1.91 级/局），对 v1.4.1 模型胜率 58.2%（+0.46 级/局）。
- **安装不再占用 C 盘（v1.5.1）**：Python、下载缓存、虚拟环境和训练数据全部放在安装文件夹里，可以把整个文件夹放在 D 盘等任意位置。
- **训练默认加上辅助任务**（`--aux 0.25`）：训练时让网络同时预测其他三家的手牌（对战时不用）。从同一个模型出发各练 2 小时，加辅助任务的模型对普通训练每局多赢 0.39 级（胜率 57.4%），对规则 AI 胜率 83.2%（普通训练 80.4%）。训练中心“更多参数”里可以调。
- **对战默认只用神经网络出牌**：随包模型练强以后，推演搜索反而让它变弱（对规则 AI +1.27 对 +1.52 级/局），“推演搜索”改为实验选项。
- 训练名称如果是 Windows 的保留名（aux、con、nul 等）会自动加上后缀，避免文件夹无法读取。

### v1.4 新增

### v1.3 新增

- **更强的随包模型**：在原模型基础上继续纯自对弈训练（累计约 3.14 亿样本）。只用网络时，对规则 AI 每局胜率从 60.7% 提高到 **71.5%**（平均每局 +0.53 → **+1.19** 级），直接对 v1.1 随包模型胜率 65%（复式对局 2000 局）。

- 训练默认回到纯自对弈（ε=0.02）：2+2 小时的对比实验中，纯自对弈明显好于对手池训练（直接对打每局多赢 0.34 级），对手池改为可选项。
- 训练中心的评估记录显示误差范围（±），说明复式评估的含义。

### v1.1 新增

- **AI 深度思考（推演搜索）**：出牌前随机推测对手手牌，把网络认为最好的几手在多个可能的牌局里推演下去，按平均结果出牌。整个过程不用人工规则。
- **计分倍数**：只算升级 / 标准倍数 / 全炸翻倍三种计分可选，牌桌显示实时倍数，结算显示底分 × 倍数。

### 内容

- 完整掼蛋规则：逢人配、钢板、三连对、同花顺、天王炸、进贡 / 还贡 / 抗贡、接风、双上升三级、过 A、打 A 三次不过退回 2
- Rust 规则引擎 + PyTorch 深度蒙特卡洛自对弈训练，模型大小可选（推荐 medium：2.46M 参数，fp16 约 5 MB）
- 训练中心：从零或从基准模型训练，复式评估的胜率曲线（对规则 AI / 基准模型 / 随机）；同一时间只运行一个训练，自对弈进程数按显存和内存自动限制，停止无响应时自动强制结束
- 教学模式（AI 提示、出牌点评、明牌）与实战模式（20 秒限时，超时随机出牌，出完可看队友牌）
- 快速对局（随机级牌）与竞技模式（打到 A）
- `guandan-medium.pt`：随包模型，GPU 自对弈约 8.8 亿样本，只用网络时对规则 AI 每局胜率 83.7%（见 docs/MODEL.md）
