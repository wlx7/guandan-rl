# 架构说明

```
┌──────────── 浏览器（主机 / 局域网手机） ────────────┐
│  web/  原生 JS：首页、开桌、加入、牌桌、训练中心        │
└───────────────▲──────────────────────▲─────────────┘
                │ WebSocket（对局）      │ REST（训练、模型、房间）
┌───────────────┴──────────────────────┴─────────────┐
│ server/app.py  FastAPI + uvicorn，监听 0.0.0.0        │
│   room.py     座位、回合循环、20 秒计时、AI 提示 / 点评 │
│   trainer.py  以子进程启动 / 停止训练，读取指标         │
└───────────────▲──────────────────────▲─────────────┘
                │                      │ python -m guandan.train
        guandan._core (Rust)     ┌─────┴──────────────────────────┐
        Game：单局状态、合法出牌   │ actor × N（CPU，各跑 64 局 VecEnv）│
        classify：人类出牌校验    │   └─ 打包样本 → 队列              │
                                 │ learner（GPU）：回放池 → MSE     │
                                 │ evaluator：定期对规则 AI / 基准   │
                                 └────────────────────────────────┘
```

## Rust 引擎

- **牌的表示**：54 种牌型 × 计数（两副牌最多 2 张）。出牌只记录牌型，不区分两张一模一样的牌。
- **合法出牌生成**（`moves.rs`）：给定手牌、级牌和要压的牌，枚举所有牌型。对逢人配采用“只在缺牌时才用”的原则，避免无意义的重复动作；挑选具体花色时优先保留能组成同花顺的牌。领出时通常有 100–300 种出法。
- **牌型识别**（`classify`）：给定玩家点选的一组牌，列出它的所有合法解释（例如 7 7 7 + 两张逢人配 = 5 张炸弹 或 三带二）。服务器用它校验人类出牌，所以人类可以任意选择花色和逢人配的用法。
- **状态机**（`game.rs`）：进贡 / 还贡阶段、出牌阶段、一局结束、整场结束。轮转时跳过已出完的玩家；“其他仍在打的人都不要”时结束一轮，最后出牌的人如已出完则由对家接风。
- **VecEnv**：在 Rust 内维护多局比赛、缓存特征、记录每名玩家的轨迹，一局结束时给轨迹打上该局的回报并输出成连续的字节数组。Python 侧只负责网络推理。

性能（单核）：随机策略下每秒约 6.6 万次决策（含全部特征编码），medium 模型 CPU 推理时每进程每秒约 3,600 次决策。

## 训练进程

- `actor_main`：每个进程一个 `VecEnv(64)`，每步把所有对局的候选出牌拼成一个批次，网络一次前向打分，ε-greedy 选择。样本按位打包（约 0.7 KB/条）后放进队列。
- 学习进程：回放池（默认 20 万条，按位存储），每条样本平均训练 `reuse` 次；每 10 次更新把权重写入共享内存，actor 发现版本号变化后加载。
- 评估进程：检查点更新后，用 CPU 与随机出牌、规则 AI、基准模型各打 400 局，结果写入 `metrics.jsonl`。
- 停止：训练中心写入 `STOP` 文件，学习进程保存检查点后退出。用同一名称再次启动即继续训练。

## 对战服务器

- 一台主机同时只有一张牌桌。开桌者拿到座位令牌；局域网玩家通过 `/api/room/join` 选座并拿到令牌；没有令牌的连接是观战者。
- 每次状态变化都向每个连接推送**个性化视图**：
  - 实战模式：只有自己的手牌；自己出完后多一份队友的手牌。
  - 教学模式与观战：所有人的手牌（教学模式默认盖住，点“明牌”才显示）。
- AI 推理在线程池中执行，不阻塞事件循环；AI 出牌前有 0.5–1.4 秒的“思考”延迟（可调速度）。
- 实战模式计时 20 秒，超时用 `random_move` 从合法出牌中随机选一手（有牌可出时不会选“不出”）。
